## 1. 문제 정의

### 1.1 배경 (UD-24 확정)

- **위키 본문**: 한국어만 (원본 언어 무관하게 종합)
- **Evidence 발췌**: 원본 언어 그대로 (번역 금지 - FR-UIX-13)
- **결과**: 같은 화면에 한국어 본문과 영어/다국어 발췌가 혼합됨

## 2. 설계 결정

### 2.1 언어 배지 (갭 #14)

**적용 대상**: 모든 Evidence 발췌문

**형식**: 발췌문 상단에 [언어] 배지

- 배지 스타일:
  - 배경: 밝은 회색 (#f5f5f5)
  - 글꼴: 소형 대문자 (font-size: 11px, font-weight: 600)
  - 패딩: 4px 8px

**다국어 표시**:
- en → [English]
- ko → [한국어] (또는 생략 가능)
- fr → [Français]

### 2.2 시각적 구분

**발췌문 컨테이너**:
- **배경색**: 연한 회색 (#f9f9f9)
- **글꼴**: monospace (Courier New, Consolas)
- **테두리**: 좌측 2~3px 진회색 세로줄
- **패딩**: 12px 16px

### 2.3 "원문" 표시

발췌문 상단 메타데이터에:
- 출처명 옆에 (English) 또는 (한국어) 추가
- "발췌" 라벨 뒤에 (원문) 표시

## 3. 적용 화면

### 3.1 문서 페이지 (근거 보기)

각 근거별로:
- 원본 제목
- [English] 배지
- 발췌 텍스트 (mono, 회색 배경)
- 신뢰도 스타

### 3.2 변경 검토 화면

변경된 발췌는 diff에서:
- +[English] 배지도 함께 표시
- 배경색·글꼴 일관되게 적용

## 4. 용어 병기 처리 (UD-27 확정)

**본문의 병기** (FR-UIX-14):
1. 초회 등장: 1회만 병기 (예: 주의 기제(attention mechanism))
2. 이후 같은 페이지: 한국어만
3. 정의 섹션·핵심 주장: 병기 유지

**발췌문의 병기**:
- 원문 그대로 (병기 추가 금지)

## 5. API 필드

**Evidence 발췌 응답**:
- excerpt: 발췌 텍스트
- excerptLanguage: "en", "ko", "fr" 등 (BCP 47)
- sourceTitle: 출처명
- confidence: 신뢰도 (0~1.0)

## 6. 컴포넌트 구조

ExcerptBlock.tsx:
- Props: excerpt, language, sourceTitle, confidence
- 렌더링: 배지 + mono 글꼴 + 회색 배경

CSS 모듈:
- excerpt-typography.module.css
- 배경색, 글꼴, 테두리 스타일

## 7. 미확정 사항

- 언어 아이콘 (국기 이모지) 추가 여부
- 검색 하이라이트 포함/제외
- 병기 Diff 표시 방식 (갭 #16)
